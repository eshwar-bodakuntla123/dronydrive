# Dronydrive Pro Design Update

This version is a real landing-page redesign, not a color override.

Design decisions:
- Unified dark graphite + green visual language across the public site.
- Inter + DM Mono hierarchy.
- True 360° hero remains intact.
- Scroll storytelling is tightened and visually connected.
- Free 360° Viewer remains the same browser-only functionality the client approved.
- Stock imagery is removed from the new scroll story; the supplied Dronydrive panorama is used to keep the visual identity consistent.
- Workflow/capability sections use a consistent grid, spacing, border and interaction system.
- Final CTA returns to the actual panorama for continuity.
- Workspace is left as a separate application surface so its existing functionality is not damaged.

Run:
cd frontend
npm install
npm run dev

Production:
npm run build
